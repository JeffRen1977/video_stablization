# Chapter 17.4 - Experimental Results

This directory contains experimental results and outputs from running the stabilization methods.

## Contents

- `results/` - Output videos and experimental data

## Results Structure

```
results/
├── nndvs_out.mp4              # NNDVS stabilized video
├── globalflownet_out.mp4       # GlobalFlowNet stabilized video
├── nndvs_evaluation.json       # NNDVS evaluation metrics
├── globalflownet_evaluation.json  # GlobalFlowNet evaluation metrics
└── comparison/                 # Comparison analysis results
```

## Viewing Results

### Video Outputs
- `nndvs_out.mp4` - NNDVS stabilized output
- `globalflownet_out.mp4` - GlobalFlowNet stabilized output

- JSON files contain detailed metrics (temporal smoothness, performance, etc.)
